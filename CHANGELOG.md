# Changelog

## 2.0.0

- Replaced the unmaintained jQuery qTip2 tooltip stack with Floating UI.
- Removed the qTip2 and imagesloaded assets; use the `efn_enable_tooltips` filter to disable tooltips.
- Preserved interactive HTML, including links, inside footnote tooltips and improved keyboard and touch dismissal behavior.
- Fixed homepage and archive footnote numbering so each post resets its footnote state independently.
- Tested with WordPress 7.1.
